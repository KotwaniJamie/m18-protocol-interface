# Raw captures

Unprocessed `--ss` dumps, one file per pack, named by e-serial. These are the raw
register values in `data_id[]` order with no interpretation applied.

Kept because re-handling a battery costs more than storing a text file. Phase 2 will
supersede these with structured JSON, but these stay as the record of what the wire
actually said on the day.

- `pack_4769294_ss.txt` — 2026-09-04, the known-good reference pack. See CLAUDE.md.
